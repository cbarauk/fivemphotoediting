Adjust
Light · color · detail
Stretches each channel's tonal range, adds a gentle contrast curve, plus vibrance and sharpening. Fully editable afterwards.
Auto corrections
Auto fixes write into the active curve layer (Curves panel). Auto Tone stretches each channel, Auto Contrast stretches luminosity only, Auto Color neutralises colour casts.
Curve layers
Apply in list order (first row first). Drag rows to reorder · the eye toggles bypass · the faint line shows the combined result.
